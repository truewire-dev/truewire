# Examples

Real projects generated by Truewire, kept green in CI.

- `kraken/`: Kraken's REST, WebSocket streams and WebSocket trading RPC. 75 endpoints, a
  hand-written core (auth, envelope, errors), recorded examples, and replay tests against
  `truewire mock`. Run `truewire check`, `truewire generate python` and
  `PYTHONPATH=src pytest` inside the directory.

- `github/`: GitHub's REST API, repository-scoped: repository metadata, commits, tags,
  releases and issues. 6 endpoints, the stock `truewire init` core with three headers added,
  and 11 examples captured live from `api.github.com` by `test/capture.py`, including two
  real multi-page walks that drive the generated `_paged` methods. Run `truewire check`,
  `truewire generate python` and `PYTHONPATH=src pytest` inside the directory; re-run
  `python test/capture.py` to refresh the recordings.
