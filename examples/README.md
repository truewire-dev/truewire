# Examples

Real projects generated by Truewire, kept green in CI.

- `kraken/`: Kraken's REST, WebSocket streams and WebSocket trading RPC. 75 endpoints, a
  hand-written core (auth, envelope, errors), recorded examples, and replay tests against
  `truewire mock`. Run `truewire check`, `truewire generate python` and
  `PYTHONPATH=src pytest` inside the directory.

- `github/`: GitHub's REST API, repository-scoped: repository metadata, commits, tags,
  releases and issues. 6 endpoints, the stock `truewire init` core with three headers added,
  and 11 examples recorded from `api.github.com` with `truewire capture` (see
  `test/recapture.sh`), including two real multi-page walks that drive the generated `_paged`
  methods. Generated in all three languages: run `truewire check`, `truewire generate
  python` and `PYTHONPATH=src pytest` inside the directory for Python, `truewire generate
  typescript` and `yarn test` for TypeScript, `truewire generate rust` and `cargo test` for
  Rust (its `Cargo.toml` names `src/github/lib.rs` as the library, and `tests/` replays the
  same recordings through the Rust client); re-run `sh test/recapture.sh` to refresh the
  recordings.
